# Meena-platoo

ระบบจัดการสต๊อกและการดำเนินงานของร้านมีนาปลาทู (Meena Inventory)

- **คู่มือการใช้งาน (ภาษาไทย):** [docs/USER_GUIDE.md](docs/USER_GUIDE.md)
- **สเปกระบบ:** [plan.md](plan.md)
- **สำหรับนักพัฒนา:** [CLAUDE.md](CLAUDE.md) — คำสั่ง, โครงสร้าง, กฎของระบบสต๊อก

```bash
npm install
npm run seed      # สิทธิ์ / บทบาท / Zone / หมวดหมู่และหน่วยพื้นฐาน / ผู้ใช้เจ้าของ
npm run dev:api   # http://localhost:3000/api
npm run dev:web   # http://localhost:5173
```
