# คู่มือการใช้งาน Meena Inventory (ร้านมีนาปลาทู)

คู่มือนี้อธิบายการใช้งานระบบสต๊อกแทน Google Sheets เดิม เรียงตามงานที่ทำจริงในแต่ละวัน
ชื่อเมนูในคู่มือตรงกับเมนูด้านซ้ายของระบบ

---

## 1. ภาพรวม: ชีตเดิม → เมนูในระบบ

| ชีตเดิม (Google Sheets) | ใช้เมนูไหนในระบบ |
|---|---|
| ห้องเย็น, สต๊อกห้องเย็น, อัพเดตห้องเย็นทุกวัน, เนื้อสัตว์, ปลาทู | Zone **ห้องเย็น** + เมนู รับสินค้า / จ่ายสินค้า / ใบเบิก + รายงาน **สต๊อกรายวัน** |
| ห้องสต๊อก, ของแห้ง, น้ำ, แพ็คแกจ | Zone **คลังสินค้า** (แยกด้วยหมวดหมู่) |
| ผัก | หมวดหมู่ **ผัก** (รับเข้าเป็นกิโลกรัม) |
| p7, ฟอร์ม, portion 7, ฟอร์ม portion | เมนู **แปรรูป / แบ่ง Portion** |
| พนักงาน | จ่ายสินค้าโดยเลือกเหตุผล **อาหารพนักงาน** (หรือหมวดหมู่ ของพนักงาน) |
| วางบิลปลาทู | รายงาน **ใบวางบิล Supplier** |
| รายการซื้อของแห้ง | เมนู **จัดซื้อ** หรือ **รับสินค้า** (ระบุ Supplier) + รายงานจัดซื้อ |
| ไวน์, ชีต19 (ไวน์พี่หยง) | ตั้ง **เจ้าของสินค้าฝากขาย** ที่วัตถุดิบ + รายงาน **สินค้าฝากขาย** |
| ยอดขาด / ยอดเกิน | เมนู **ตรวจนับสต๊อก** |

**หลักการสำคัญ**
- ทุกครั้งที่ของเข้า ออก หรือย้าย ระบบบันทึกประวัติไว้เสมอ (ดูได้ที่ **ประวัติการเคลื่อนไหว**) และแก้ประวัติย้อนหลังไม่ได้ ถ้าบันทึกผิด ให้แก้ด้วย **ปรับปรุงสต๊อก** พร้อมระบุเหตุผล
- สต๊อกไม่ติดลบ ถ้าของในโซนไม่พอ ระบบจะไม่ยอมให้บันทึก

## 2. เริ่มต้นใช้งานครั้งแรก (สำหรับเจ้าของ/ผู้จัดการ)

1. **ตรวจ Zone** ที่ ข้อมูลพื้นฐาน → Zone
   - ระบบมีให้แล้ว 4 โซน คือ คลังสินค้า, ครัว (Kitchen), หน้าร้าน (Front of House) และห้องเย็น (Cold Room)
   - ติ๊ก **"รับสินค้าจาก Supplier เข้า Zone นี้ได้โดยตรง"** ให้โซนที่รับของจากผู้ขายตรง เช่น ห้องเย็นที่รับปลาทูจากพี่กิ่ง (คลังสินค้ารับได้เสมอ)
   - อยากแยกที่เก็บเพิ่ม เช่น "ตู้แช่ไวน์" ให้กด **สร้าง Zone** ใหม่ได้เลย
2. **ตรวจหน่วยนับ** ที่ ข้อมูลพื้นฐาน → หน่วยนับ ระบบมีหน่วยพื้นฐานให้แล้ว เช่น กิโลกรัม กรัม ลิตร ถุง ลัง ขวด แพ็ค กล่อง ตัว
3. **นำเข้ารายการวัตถุดิบจาก Excel** (ดูข้อ 4) แทนการคีย์ทีละรายการ
4. **ตั้งยอดยกมา** ให้ตรงกับของจริง ทำได้ 2 วิธี
   - ใส่คอลัมน์ "Zone ยอดยกมา" และ "ยอดยกมา" ในไฟล์นำเข้า หรือ
   - นับของจริงด้วยเมนู **ตรวจนับสต๊อก** แล้วอนุมัติ
5. **สร้างผู้ใช้งาน** ที่ จัดการระบบ → ผู้ใช้งาน กำหนดบทบาทและ Zone ที่แต่ละคนเข้าถึงได้

## 3. หน่วยนับและการแปลงหน่วย (ลัง / ถุง / ขวด / กรัม)

ระบบเก็บสต๊อกของแต่ละวัตถุดิบเป็น **หน่วยหลัก** เพียงหน่วยเดียว แต่ตอนรับ จ่าย เบิก หรือสั่งซื้อ เลือกคีย์เป็นหน่วยอื่นได้ แล้วระบบแปลงให้อัตโนมัติ

| ตัวอย่าง | ตั้งค่า | คีย์ | ระบบบันทึก |
|---|---|---|---|
| เบียร์ | หน่วยหลัก = ขวด, หน่วยแพ็ค 1 ลัง = 12 ขวด | รับ 2 ลัง | +24 ขวด |
| ตีนไก่ | หน่วยหลัก = กิโลกรัม, 1 ถุง = 5 กก. | เบิก 3 ถุง | −15 กก. |
| แซลม่อน | หน่วยหลัก = กิโลกรัม | รับ 4,900 กรัม | +4.9 กก. (กรัม↔กิโลกรัม แปลงให้เอง) |

**ตั้งหน่วยแพ็ค** ไปที่ ข้อมูลพื้นฐาน → วัตถุดิบ → แก้ไข → ส่วน **หน่วยแพ็ค / หน่วยแปลง** แล้วกรอก "1 ลัง = 12 ขวด" (เพิ่มได้หลายหน่วย)

**ราคาตามหน่วยที่เลือก** ถ้ารับเข้า 2 ลัง แล้วกรอก "ต้นทุนต่อลัง 600" ระบบจะคิดเป็นขวดละ 50 บาท

**แสดงแบบมีเศษ** หน้าสต๊อกคงเหลือแสดงยอดแยกเป็นแพ็คให้ด้วย เช่น 26 ขวด = "2 ลัง 2 ขวด"

> หน้า หน่วยนับ ใช้กำหนดตัวคูณเฉพาะหน่วยน้ำหนักและปริมาตร (กรัม = 0.001 ของกิโลกรัม, มิลลิลิตร = 0.001 ของลิตร) ส่วนขนาดแพ็คอย่าง "1 ลัง = 12 ขวด" ต่างกันไปในแต่ละสินค้า จึงตั้งที่หน้าวัตถุดิบแทน

## 4. นำเข้าวัตถุดิบจาก Excel

เมนู: ข้อมูลพื้นฐาน → **นำเข้าจาก Excel** (สิทธิ์ `ingredients.import` ซึ่งเจ้าของและผู้จัดการมีอยู่แล้ว)

1. กด **ดาวน์โหลดไฟล์ตัวอย่าง** แล้วกรอกข้อมูล หรือใช้ไฟล์ที่เตรียมไว้แล้ว (Google Sheets ใช้ได้ โดยไปที่ ไฟล์ → ดาวน์โหลด → .xlsx หรือ .csv)
2. เลือกไฟล์ `.xlsx` หรือ `.csv` ระบบจะ **ตรวจสอบก่อน โดยยังไม่บันทึกอะไร** และแสดงผลทีละแถวว่าเป็น "สร้างใหม่", "อัปเดต" หรือ "มีปัญหา"
3. แก้แถวที่มีปัญหาในไฟล์แล้วอัปโหลดใหม่ หรือกด **ยืนยันนำเข้า** ได้เลย (แถวที่มีปัญหาจะถูกข้าม)

### คอลัมน์ในไฟล์ (แถวแรกต้องเป็นหัวคอลัมน์)

| หัวคอลัมน์ | จำเป็น | ความหมาย |
|---|---|---|
| รหัส | – | รหัสวัตถุดิบ ถ้าเว้นว่าง ระบบตั้งให้ (ING-0001, …) ถ้าใส่รหัสที่มีอยู่แล้ว จะเป็นการอัปเดตรายการนั้น |
| ชื่อวัตถุดิบ | ✔ | ถ้าไม่ใส่รหัส ระบบจับคู่กับของเดิมด้วยชื่อ |
| หมวดหมู่ | ✔ | ชื่อหรือรหัสหมวดหมู่ ถ้ายังไม่มี ระบบสร้างให้ |
| หน่วยหลัก | ✔ | หน่วยที่ใช้เก็บสต๊อก เช่น ถุง, ขวด, กิโลกรัม ถ้ายังไม่มี ระบบสร้างให้ (เปลี่ยนหน่วยหลักของรายการเดิมผ่านการนำเข้าไม่ได้) |
| หน่วยแพ็ค | – | หน่วยใหญ่ เช่น ลัง |
| จำนวนต่อแพ็ค | – | 1 หน่วยแพ็ค = กี่หน่วยหลัก เช่น 12 |
| สต๊อกขั้นต่ำ / สต๊อกสูงสุด | – | ใช้เตือนของใกล้หมด (หน่วยหลัก) |
| ต้นทุนต่อหน่วยหลัก | – | ต้นทุนมาตรฐาน (บาท) |
| แท็ก | – | ป้ายเพิ่มเติม คั่นด้วยจุลภาค เช่น `portion, พนักงาน` |
| เจ้าของสินค้าฝากขาย | – | ใส่เฉพาะสินค้าฝากขาย เช่น `ไวน์พี่มี่` |
| รายละเอียด | – | หมายเหตุ |
| Zone ยอดยกมา | – | ชื่อหรือรหัส Zone เช่น ห้องเย็น, คลังสินค้า, ครัว, หน้าร้าน |
| ยอดยกมา | – | **ตั้ง**สต๊อกของ Zone นั้นเป็นจำนวนนี้ (หน่วยหลัก) ต้องใส่ Zone คู่กันด้วย |

**หมายเหตุ**
- นำเข้าไฟล์เดิมซ้ำได้ ระบบจะอัปเดตรายการเดิม ไม่สร้างซ้ำ
- ยอดยกมา **แทนที่** ยอดเดิมของ Zone นั้น (ไม่ได้บวกเพิ่ม) และบันทึกเป็นการปรับสต๊อก เหตุผล "ยอดยกมา (นำเข้าจาก Excel)"
  - ตอนตรวจสอบ ระบบจะแสดง "⚠ ยอดปัจจุบัน A จะถูกตั้งเป็น B (±ส่วนต่าง)" ให้ทุกแถวที่จะเปลี่ยนยอดของเดิม
  - ถ้าแค่ต้องการแก้ข้อมูลอื่น เช่น สต๊อกขั้นต่ำหรือแท็ก ให้**ลบค่าในคอลัมน์ยอดยกมาออกก่อน** ไม่อย่างนั้นสต๊อกจริงจะถูกเขียนทับ
- ผู้ที่จะใส่ยอดยกมาได้ ต้องมีสิทธิ์ปรับสต๊อก และมีสิทธิ์เข้าถึง Zone นั้น
- ถ้ามีแถวชื่อซ้ำ (หรือรหัสซ้ำ) ในไฟล์เดียวกัน ระบบใช้แถวแรก และแจ้งปัญหาที่แถวหลัง
- ไฟล์ที่ได้จากปุ่ม **Excel (แก้แล้วนำเข้ากลับได้)** ในหน้าวัตถุดิบ ใช้หัวคอลัมน์เดียวกับไฟล์นำเข้า จึงแก้ไขแล้วนำเข้ากลับได้เลย

## 5. งานประจำวัน

> **เลือกวัตถุดิบ**: ทุกช่องที่ต้องเลือกวัตถุดิบ พิมพ์ส่วนหนึ่งของชื่อหรือรหัสเพื่อค้นหาได้ (เช่น พิมพ์ "แซล" จะเจอ "ปลาแซลม่อน") ใช้ลูกศรขึ้น/ลงแล้วกด Enter หรือแตะเลือกบนมือถือ

### 5.1 รับสินค้า (ของเข้าจาก Supplier)
เมนู: สต๊อกสินค้า → **รับสินค้า**
- เลือก **รับเข้า Zone** ได้ทั้งคลังสินค้า และ Zone ที่เปิดรับสินค้า เช่น ห้องเย็น
- เลือกวัตถุดิบ ใส่จำนวน แล้วเลือก **หน่วย** (เช่น ลัง)
- ช่องที่ไม่บังคับ: ต้นทุนต่อหน่วยที่เลือก, **Supplier**, **เลขที่บิล/ใบส่งของ**, **น้ำหนักรวม (กก.)**
- ถ้าระบุ Supplier รายการนี้จะไปขึ้นใน **ใบวางบิล Supplier**

### 5.2 จ่ายสินค้า (ใช้ / ขาย / อาหารพนักงาน)
เมนู: สต๊อกสินค้า → **จ่ายสินค้า**
- เลือก Zone, วัตถุดิบ, จำนวน และหน่วย
- เลือก **เหตุผลการเบิก** ได้แก่ ใช้ในครัว/ร้าน, **ขาย** (ใช้คิดยอดขายสินค้าฝากขาย), **อาหารพนักงาน**, ของแถม/รับรอง, อื่นๆ

### 5.3 ใบเบิกสินค้า (ครัว/หน้าร้าน ขอของจากคลังหรือห้องเย็น)
เมนู: ใบเบิกสินค้า → **สร้างใบเบิก**
- **เบิกจาก** เลือกได้ทั้งคลังสินค้า และ Zone ที่เปิดรับสินค้า (เช่น ห้องเย็น)
- คีย์จำนวนเป็นแพ็คได้ เช่น 1 ลัง แล้วระบบเก็บเป็นหน่วยหลัก
- ขั้นตอน: สร้าง → ผู้จัดการอนุมัติ → ผู้ดูแลสต๊อกจ่ายของ (ระบบโอนสต๊อกให้อัตโนมัติ) **สต๊อกจะย้ายตอนจ่ายของเท่านั้น** ไม่ใช่ตอนสร้างใบเบิก

### 5.4 โอนสินค้าระหว่าง Zone
เมนู: สต๊อกสินค้า → **โอนสินค้า** เลือกหน่วยได้ทีละรายการ ใช้ย้ายของโดยไม่ต้องผ่านใบเบิก

### 5.5 ตรวจนับสต๊อก (แทน "ยอดขาด/ยอดเกิน")
เมนู: สต๊อกสินค้า → **ตรวจนับสต๊อก**
- เลือก Zone แล้วกรอกจำนวนที่นับได้จริง สินค้าที่มีหน่วยแพ็ค กรอกเป็น "__ ลัง + __ ขวด" ได้ แล้วระบบรวมเป็นหน่วยหลักให้
- ระบบคำนวณส่วนต่าง เมื่อผู้จัดการอนุมัติ ระบบจะปรับสต๊อกให้ตรงกับที่นับ

### 5.6 ของเสีย
เมนู: ของเสีย → **รายการของเสีย** บันทึกพร้อมเหตุผลและเลือกหน่วยได้ สต๊อกจะถูกตัดเมื่อผู้จัดการอนุมัติ

### 5.7 ปรับปรุงสต๊อก
ใช้แก้ยอดที่บันทึกผิด ต้องระบุเหตุผลทุกครั้ง และเลือกหน่วยได้

## 6. แปรรูป / แบ่ง Portion (แทนชีต p7 และ portion)

เมนู: สต๊อกสินค้า → **แปรรูป / แบ่ง Portion**

ตัวอย่าง: แซลม่อน 4.9 กก. (กก.ละ 440 บาท) แบ่งเป็นแซลม่อนดอง 100 กรัม 10 ถุง และซาชิมิ 165 กรัม 9 ถุง เหลือเศษ 1.8 กก.

1. เตรียมรายการ portion เป็นวัตถุดิบไว้ก่อน (เช่น "แซลม่อนดอง 100g" หน่วยหลัก ถุง หมวดหมู่ Portion)
2. เลือก Zone ที่ทำ (เช่น ครัว) ซึ่งต้องมีวัตถุดิบตั้งต้นอยู่ใน Zone นั้น ถ้าของอยู่ห้องเย็น ให้เบิกหรือโอนมาก่อน
3. กรอกวัตถุดิบตั้งต้น + จำนวน + หน่วย และราคาทุนต่อหน่วย (ถ้าเว้นว่าง ระบบใช้ต้นทุนมาตรฐาน)
4. เพิ่มรายการ **สินค้าที่ได้** พร้อมจำนวน และ **น้ำหนัก/หน่วย (กรัม)**
5. ใส่ **เศษ/เสีย** ถ้ามี

เมื่อบันทึก ระบบจะ
- ตัดวัตถุดิบตั้งต้นออก และเพิ่มสต๊อก portion ทุกรายการพร้อมกัน (ถ้าของไม่พอ จะไม่บันทึกเลยสักรายการ)
- **กระจายต้นทุน** ตามน้ำหนัก (เมื่อกรอกน้ำหนักครบทุกรายการ) หรือเฉลี่ยต่อหน่วย (เมื่อกรอกไม่ครบ) แล้วแสดง "ตกถุงละ … บาท"
- คำนวณ **Yield %** = น้ำหนักที่ได้ ÷ น้ำหนักวัตถุดิบ (ตัวอย่างนี้ได้ประมาณ 50.7%)
- ถ้าติ๊ก "อัปเดตต้นทุนมาตรฐานของสินค้าที่ได้" ระบบจะตั้งต้นทุนมาตรฐานของ portion เป็นต้นทุนที่คำนวณได้ ตัวเลือกนี้ปิดไว้เป็นค่าเริ่มต้น และจะเห็นเฉพาะผู้ที่มีสิทธิ์แก้ไขวัตถุดิบ (เจ้าของ/ผู้จัดการ)

---

## 7. จัดซื้อ (ใบสั่งซื้อ)

- **สร้างใบสั่งซื้อ** โดยเลือกหน่วยได้ทีละรายการ เช่น สั่ง 3 ลัง ราคาลังละ 590 บาท
- ขั้นตอน: ร่าง → ส่งอนุมัติ → อนุมัติ → **รับสินค้า** (รับบางส่วนได้)
- ตอนรับสินค้า เลือก **รับเข้า Zone** ได้ (คลังสินค้า หรือ Zone ที่เปิดรับสินค้า) และกรอก **เลขที่บิล/ใบส่งของ**

---

## 8. รายงาน

| รายงาน | ใช้ทำอะไร |
|---|---|
| **สต๊อกรายวัน** | ตารางแบบเดียวกับชีตเดิม: ยอดยกมา / รับเข้า / เบิกออก / คงเหลือ ต่อรายการ เลือก Zone, หมวดหมู่ และช่วงวันที่ได้ (ไม่เกิน 62 วัน) กด "แสดงแยกรายวัน" เพื่อดูทีละวัน ถ้าเลือก "ทุก Zone" ระบบไม่นับการโอนระหว่าง Zone เพราะยอดรวมของร้านไม่เปลี่ยน |
| **ใบวางบิล Supplier** | เลือก Supplier และช่วงวันที่ จะได้ใบวางบิลพร้อมพิมพ์ ประกอบด้วยวันที่ รายการ จำนวน (ตามหน่วยที่รับจริง เช่น ลัง) ราคาต่อหน่วย จำนวนเงิน เลขที่บิล และยอดรวม |
| **สินค้าฝากขาย** | แยกตามเจ้าของ: ยกมา, รับเข้า, ขายออก (จากการจ่ายสินค้าเหตุผล "ขาย"), มูลค่าขายตามราคาทุน, ออกอื่นๆ, คงเหลือ ณ วันสุดท้ายของช่วง โดย ยกมา + รับเข้า − ขายออก − ออกอื่นๆ = คงเหลือ (รวมทุก Zone ไม่นับการโอนระหว่าง Zone) |
| รายงานสต๊อก / ตาม Zone / ใบเบิก / จัดซื้อ / ของเสีย / ต้นทุน / เปรียบเทียบ | รายงานเดิม (นับรวมการแปรรูปด้วยแล้ว) |

**ส่งออกไฟล์**: หน้ารายการและรายงานเดิมมีปุ่ม **CSV** / **PDF** (ต้องมีสิทธิ์ส่งออกของหน้านั้น) ส่วนรายงานใหม่ (สต๊อกรายวัน, ใบวางบิล, สินค้าฝากขาย), ประวัติการแปรรูป และหน้าวัตถุดิบ มีปุ่ม **Excel** ที่ดาวน์โหลดตามข้อมูลที่กรองอยู่บนหน้าจอ

## 9. สินค้าฝากขาย (เช่น ไวน์พี่มี่, ไวน์พี่หยง)

1. ที่ ข้อมูลพื้นฐาน → วัตถุดิบ ใส่ **เจ้าของสินค้า (กรณีฝากขาย)** ให้รายการนั้น
2. ของเข้า ให้บันทึกที่ **รับสินค้า**
3. ขายออก ให้บันทึกที่ **จ่ายสินค้า** แล้วเลือกเหตุผล **ขาย**
4. ดูสรุปเพื่อเคลียร์เงินกับเจ้าของที่ รายงาน → **สินค้าฝากขาย**

ถ้าต้องการแยกไวน์ "ในห้องสต๊อก" กับ "ในตู้แช่" ให้สร้าง Zone "ตู้แช่ไวน์" แล้วใช้ **โอนสินค้า** เมื่อย้ายขวดเข้าตู้

## 11. คำถามที่พบบ่อย

**คีย์หน่วยแล้วขึ้นว่า "ไม่ได้ตั้งค่าการแปลงหน่วย"**: วัตถุดิบนั้นยังไม่มีหน่วยแพ็คนี้ ให้เพิ่มที่หน้าวัตถุดิบก่อน

**รับสินค้าเข้าครัวไม่ได้**: ครัวไม่ได้เปิดรับสินค้า ให้รับเข้าคลังหรือห้องเย็นแล้วเบิก/โอนไปครัว หรือเปิดสิทธิ์รับสินค้าให้ Zone ครัวที่หน้า Zone

**บันทึกผิดไปแล้ว**: ประวัติแก้ไม่ได้ ให้ใช้ **ปรับปรุงสต๊อก** เพื่อปรับยอดกลับพร้อมเหตุผล

**ยอดในรายงานสต๊อกรายวันกับหน้าสต๊อกคงเหลือไม่ตรงกัน**: ยอดคงเหลือในรายงานคือยอด ณ สิ้นวันสุดท้ายของช่วงที่เลือก ถ้าเลือกช่วงที่จบวันนี้ ยอดจะตรงกับหน้าสต๊อกคงเหลือ
